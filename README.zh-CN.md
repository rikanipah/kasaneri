# Kasaneri

# 注意
>
> **本项目大部分代码是借助 ChatGPT、DeepSeek 等模型 vibe coding 写出来的，是实现本人一些想法的实验性尝试。**
>
> 应用面向的需求**高度个性化**，且目前仍需要在本人长期使用中测试和优化，虽然有安装包，但仅仅作为想法如何实现的参考，**没有考虑**其他用户的使用和体验！！
>
> 发布此项目**仅仅**为了提供一些想法和功能实现的参考，同时便于记录留存。所以这意味着应用并没有使用太长时间，**全是BUG**!!

## 这是什么

Kasaneri是一个以 [FSRS 记忆算法](https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler)、[渐进阅读](https://www.masterhowtolearn.com/2018-10-28-why-i-switched-to-supermemo/) 等理论为基础，借鉴了 [SuperMemo](https://supermemo.com)、[Anki](https://apps.ankiweb.net)等项目功能的学习工具。

Kasaneri 的复习与推送二者是区别开的：Kasaneri 可以建立主题卡，通过待办机制不断将需要学习的内容主动推送，对其建立提取卡，不断修改并提炼知识点建立检测卡；检测卡创立后即进入复习机制，利用 FSRS 算法，随即可以复习检测卡，也可以让检测卡回到推送机制进行修改，直到能够掌握相应知识点。

Kasaneri的编辑界面基于Electron，简洁美观。

代码结构见 [CODE.md](CODE.md)。本项目用 MIT 许可证，全文见仓库根目录的 [LICENSE](LICENSE)。

## 为什么做这个

1. Anki 里卡片被暂停之后，很多时候没有动力回头处理。暂停卡越堆越多，越堆越不想碰，导致恶性循环。本人希望有类似 SuperMemo 的推送机制，来让一些记忆卡片不断被推回来修改、优化。

2. 参考渐进阅读，某些卡片要先掌握逻辑前提才能够理解。比如（卡片 A）范特霍夫等压方程式

   $\displaystyle \left( \dfrac{\partial \ln K^\ominus(T)}{\partial T} \right)_p = \dfrac{\Delta_r H^\ominus}{RT^2}$

   既需要理解化学上 $K^{\ominus}(T),\ R,\ \Delta_{r}H^{\ominus}$ 的意思（相近领域的 A1、A2、A3），也需要理解数学上微分的含义（较远领域的B1）。如果逻辑前提意味上的知识没掌握，尽管可以临摹记忆公式，但效率也不是很高。

3. 本人喜欢 Obsidian 的使用，习惯 Markdown 编辑资料，基于Electron也容易个性化修改。

4. 为什么不写 Anki 或 Obsidian 的插件：写插件受软件本身限制，很多功能都要大改，底层也不同。现在 AI Agent 已经能写掉大部分体力活，除了钱包和时间两空外没什么大代价。

5. 闲的，有意思，想在尝试中学习相关流程和知识。

## 复习

排程用 [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)（FSRS-6 / FSRS-7 可切换），参数优化调官方的 [@open-spaced-repetition/binding](https://github.com/open-spaced-repetition/ts-fsrs/tree/main/packages/binding)。

大部分参考 Anki，但存在不一样的几条功能。

### 暂停拆成待办暂停和留存判定

Anki 的“暂停”改为不同含义的两个部分：

- **待办暂停**：检测卡片退出复习，进入待办，由待办的算法来多次推送，进行检测卡片的编辑与优化；在待办里处理好后，点击“返回复习”就能取消待办暂停，重新进复习，此时检测卡片此前的评分会被清空，作为“新卡片”来推送，但卡片本身操作信息（待办、复习的评分记录）保留。
- **留存判定**：对检测卡片打上留存判定的状态，此时卡片不会待办、复习推送，但可以从浏览卡片中翻阅对应卡片，自行判断是否要保留或者删除。

### leech 可以循环

一张卡连续重来达到阈值时（默认为 4 次），会自动变成待办暂停，打上 leech 属性。

在待办里点“返回复习”时，卡片的记忆状态会整体清零、当作新卡重新计分（稳定性、难度、次数、到期都重置），复习记录和 leech 属性都保留。下一轮又从 4 次重新开始，反复循环。撤销这次“返回复习”会把状态一起还原。

leech 属性后面带累计重来次数，比如 leech(6)，一眼能看出循环了几轮（撤销掉的评分不算）。一般靠手动删除，撤销那次触发它的评分也会还原。

### 优先级

检测卡可以设类似 SuperMemo 的优先级，0 到 9，不设就继承上级文件夹。它不参与 FSRS 的记忆计算，只影响推送间隔，参考推送机制。

### 先修卡

父子卡关系就是先修关系：子卡没掌握，父卡就不会进入复习队列（父卡依赖子卡，方向是子 → 父）。解锁条件是子卡“连续 N 次良好”，N 默认 4，可以在复习设置里改。参考为什么做的第二条。

## 推送

参考 SuperMemo 的渐进阅读。

待办队列的算法暂时参考 Foliole 的算法，仅参考了算法，推送机制有改变。

材料推送时，

| 操作 | 后续安排 |
| --- | --- |
| **读完** | 若完成了本次推送的阅读，点击读完，则会在延后一段时间继续推送。 |
| **稍后** | 若本轮阅读推送未完全完成，点击稍后，则会在比阅读的时间更短时间间隔内再次推送。 |
| **完成** | 若完全完成了推送的卡片，则点击完成，卡片将不会再次推送。 |

读的时候可以随时改正文、摘录、生成子卡。

## 目录树和记忆树

### 目录树

便于查看卡片层级关系的树。

文件夹下面放主题、提取、检测卡，可以任意嵌套。顶部按照主题、提取、检测卡的颜色有三个不同颜色的按钮，可按类型筛选筛仅可见什么类型的卡片。

### 记忆树

便于查看先修卡和关联卡片的树。

在右侧下区，显示当前卡的父卡、子卡和关联卡。父子关系就是先修关系；关联卡是可以自行设立的跳转链接，仅仅作为快速跳转。

## 安装说明

在 [GitHub Releases](https://github.com/rikanipah/Kasaneri/releases/latest) 下载 Windows 安装包或 Linux x64 压缩包。同一页面提供 SHA-256 校验文件。

### Windows

1. 下载 `Kasaneri-Setup-<版本号>.exe` 安装包。
2. 双击安装，按向导走完即可。按用户安装，默认装到 `%LOCALAPPDATA%\Programs\Kasaneri`，不需要管理员权限。
3. 程序没有代码签名，Windows 可能弹「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
4. 第一次启动会让你选资料库文件夹：可以新建一个空文件夹，也可以打开已有的资料库，已有的设置会沿用。
5. 资料库是一个普通文件夹（`library.sqlite`、`assets`、`cache`），放在哪都行；升级程序和卸载都不会动它，删除需要自行删除。
6. 卸载：设置 → 应用 → Kasaneri → 卸载，或者用开始菜单里的卸载项。
7. 安装向导里显示的许可是 MIT。

已安装 Kasaneri 的用户，先退出应用，然后运行新安装包并沿用原安装目录。覆盖安装会保留资料库和设置。

### Linux x64

从 Releases 下载 Linux 压缩包。以 v0.5.1 为例，解压后这样启动：

```bash
tar -xzf Kasaneri-Linux-x64-0.5.1.tar.gz
cd Kasaneri-Linux
./run-linux.sh
```

## 其它

### 编辑

编辑器用 CodeMirror 6，Markdown 渲染，公式用 KaTeX。摘录和挖空会在原文留彩色锚点，按住ctrl后，点锚点跳回原处。图片可以粘贴或拖入，显示宽度按卡片保存。图片遮挡是在图上画框，每个框生成一张检测卡。

### 数据与备份

数据是一个 SQLite 库（WAL，schema 14），不是 Anki 的库格式，与 Anki 数据的对接待完善。资料库就是一个文件夹：library.sqlite、assets（附件按内容 sha256 去重）、cache（可重建的图片预览）。自动快照默认留最近 14 份，也能不退出程序直接做在线快照。删除都是软删除，进垃圾桶trash，彻底删除前写一份 Markdown 快照。

### 附件

附件作为对象插入正文，文件副本保存在资料库中，设置→文件里有附件管理，能把没被引用的附件移进附件回收站，也能恢复或彻底删除。

### 同步

同步是两台机器局域网直连，HTTP 38641，手填对端 IP，请求带签名和时间戳。排程靠 review_log / reading_log 收敛，正文走版本，两边都改了文件会打上“冲突文件”状态，自行手动在卡片浏览中逐张选保留哪一份。
