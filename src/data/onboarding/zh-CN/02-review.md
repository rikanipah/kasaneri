# 关于复习

目录树里每个文件夹就是一个牌组，子文件夹是子牌组。选中一个文件夹，点右侧工具栏的**复习**，或右键该文件夹选择**进入复习**。只有检测卡进复习。

参数沿父链继承最近的一次覆盖，最后回落到**设置 → 默认复习**。要给单个牌组单独设置，右键该文件夹选择**复习设置**。

空格显示答案，然后按 1 重来、2 困难、3 良好、4 简单。困难和简单按钮默认隐藏，可以在默认复习里打开。

连续「重来」达到阈值时会按 leech 设置打上标签并转到待办，方便回头修改；也可以手动用**更多 → 待办暂停**。

一时判断不了要不要留下的卡片，用**更多 → 留存判定**，之后在浏览卡片里再决定。

四种「停」：**待办暂停**退出复习、留在待办反复推送；**留存判定**两边都不推送；**搁置**只推迟到下一个日切点；**已完成**不再推送。
