# markdown示例

正文支持 Markdown 与 LaTeX，下面是一份写法速查。

## 标题与强调

# 一级标题
## 二级标题

**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

- 无序列表
- 第二项
  1. 有序列表
  2. 第二项

- [ ] 待办事项
- [x] 已完成

## 引用与代码

> 引用一行。

```js
const answer = 42;
```

## 公式

行内公式：$c = \lambda \nu$，块级公式：

$$
\Delta_r H^\ominus = \sum \nu_i \Delta_f H^\ominus_i
$$

## 表格

| 操作 | 快捷键 |

| 检测卡 | Alt+S |

## 链接与图片

[Markdown 语法](https://commonmark.org/help/)
