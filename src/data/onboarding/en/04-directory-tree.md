# Directory Tree

The Directory Tree shows how folders, topics, extracts, and test cards are nested. Click a row to select it, and use the + / − on the left to expand or collapse its children.

The three colored buttons at the top filter topics, extracts, and test cards; filters can be combined, and with all of them off every card is shown.

Right-click a folder or card for its actions: new topic, extract, or test card, rename (F2), move, delete, start review, and card info.

Hold Shift to select a range or Ctrl to pick individual cards. Right-clicking a multi-selection opens a bulk menu (move, delete all cards); a single Ctrl+Z restores the whole batch.
