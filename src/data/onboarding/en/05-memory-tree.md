# Memory Tree and Prerequisites

The Memory Tree sits in the lower right area and shows the current card's parents, children, and related links.

A parent/child pair is a **prerequisite**: a test child is a prerequisite of its parent, and the parent does not enter the review queue until its children unlock it. A child unlocks the parent after N consecutive Good or Easy ratings; N defaults to 4 and can be changed under **Settings → Review**.

Right-click a parent and choose **New test child card** to create a prerequisite. Children created in the Directory Tree appear here too. Click a card in the Memory Tree to open it in the workspace and locate it in the Directory Tree.

**Link related card…** adds a shortcut that only affects navigation, never scheduling. Prerequisites can also be added or ignored in **Card info**.
